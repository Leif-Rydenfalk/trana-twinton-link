What this is

Twinton (maps.ce-net.com) is a globe of digital twins. Trana (trana.app) is the public layer where results and reviews are posted. The relay is a deliberately small twin of the link between them: a cabinet at ce-net's home in Umeå, a beacon that turns amber when Trana's layer lags and red when either end is missing, and a panel that finds the announcement by title in the layer.

The bridge is not a copy of either side. It is one file with the link's state, the announcement id, and the age of the layer. The twin fetches it as one more data source; if the heartbeat stops, the twin says so instead of pretending the link is live.

How it stays connected

Every ten minutes (GitHub Actions' best effort) heartbeat.py fetches the twin manifest and Trana's public layer, finds the announcement, and commits bridge.json. The workflow fails when the state is not live, so a broken link is visible in the repository's Actions tab. A failed check never erases the last thread id: the next successful run restores it.

No secret is stored here. The heartbeat only reads public URLs; it does not post to Trana. The announcement post and this bridge are the two static halves; the twin's read of the layer is the live half.

Honest limits

GitHub's scheduler can run late; the page shows the heartbeat's own age, not a promise. The public layer is a snapshot with a cache window, so a just-published announcement can be absent for a few minutes. The cabinet is schematic; the arcs are links to places, not cables. The packet motion illustrates the modelled posting rhythm and is not real traffic.
